# Boucle Playlists

Lecteur web qui fait tourner plusieurs playlists YouTube en boucle (musique de fond, écran d'affichage).
Il utilise le lecteur YouTube officiel, relance la lecture si elle s'arrête et garde l'écran allumé.

## Utilisation

- **En ligne (Windows, Android…)** : ouvrir la page GitHub Pages du dépôt. Sur Android, menu de Chrome → « Ajouter à l'écran d'accueil ».
- **Sur Windows, sans internet pour la page** : double-cliquer sur `Lancer.bat` (sert `index.html` sur `http://localhost:8765`).

Ouvrir `index.html` en double-clic ne marche pas : YouTube refuse la lecture dans une page `file://`.
